Preguntas Frecuentes

El sistema Aduanas System busca reducir los tiempos de tramitación presencial (actualmente hasta 20 horas) mediante formularios web preventivos y automatización de procesos migratorios, garantizando interoperabilidad con organismos chilenos (PDI, SAG) y la Aduana Argentina.

El sistema garantiza un uptime del 99.9% (24/7), equivalente a un máximo de 43 minutos de inactividad al mes. Esto es crítico para operaciones fronterizas sin interrupciones.

Los datos de menores están protegidos mediante cifrado de extremo a extremo, autenticación de doble factor (2FA) para funcionarios y registros de auditoría completos para garantizar confidencialidad e integridad.

El sistema procesa validaciones en ≤ 2 segundos bajo condiciones normales y soporta flujo simultáneo de al menos 5.000 usuarios sin degradación del servicio.

El sistema activa el modo offline en menos de 5 segundos, permitiendo continuar con operaciones no dependientes de validación internacional, con sincronización automática al restaurar la conexión.

Sí, el sistema es completamente responsive y funciona en Chrome 120+, Firefox 120+ en desktop, tablet y móvil, facilitando el acceso para personas con poca experiencia digital.
