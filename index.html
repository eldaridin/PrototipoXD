Preguntas Frecuentes

El sistema Aduanas System busca reducir los tiempos de tramitación presencial (actualmente hasta 20 horas) mediante formularios web preventivos y automatización de procesos migratorios, garantizando interoperabilidad con organismos chilenos y la Aduana Argentina.

El sistema garantiza un uptime del 99.9% (24/7), lo que equivale a un máximo de 43 minutos de inactividad al mes. Esto es crítico para operaciones fronterizas sin interrupciones.

Los datos de menores están protegidos mediante cifrado de extremo a extremo, autenticación de doble factor para funcionarios y registros de auditoría completos (logs) para garantizar confidencialidad e integridad.

El sistema procesa validaciones en ≤ 2 segundos bajo condiciones normales y soporta un flujo simultáneo de al menos 5.000 usuarios sin degradación del servicio.

El sistema cuenta con un modo offline temporal que se activa en menos de 5 segundos ante caídas de conexión, permitiendo continuar con operaciones no dependientes de validación internacional.

Sí, el sistema es completamente responsive y funciona en navegadores modernos (Chrome 120+, Firefox 120+) en desktop, tablet y móvil, facilitando el acceso para personas con poca experiencia digital.
